# Classifying Finer Emotions in Reviews

Go beyond positive and negative to detect specific emotions such as anger and disgust in customer reviews.

## Approach

- TF-IDF features and a Logistic Regression emotion classifier
- Most frequent unigrams, bigrams and adjectives by sentiment
- Text processing with spaCy

## Results

Accuracy of about 0.57 on the multi-class emotion task in the saved notebook output.
